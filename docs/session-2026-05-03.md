# 开发日志 — 2026-05-03

## 本次完成

### 一、社区体验 + AI 助手 + 发帖提示优化

#### 修隐性数据丢失 Bug（P0）

`getPostsForFeed` / `getPostsByUserId` / `getPostById` 的 modern schema 路径只 SELECT 真实列，不解析 `content` 里的 metadata，导致 `cuisine` / `pricePerPerson` / `restaurantHint` 永远是 `undefined`。

修复：在 [server/db.ts](server/db.ts) 新增 `withClassificationMeta` helper，modern schema 返回前调用，从 content 元数据提取三个分类字段，与 `withLegacyPostDefaults` 模式对称。

#### 社区卡片新增 3 个结构化标签

[client/src/pages/Feed.tsx](client/src/pages/Feed.tsx) — 标题前加 `🛵 外卖 / 🍽 堂食` 小灰字；内容与图片之间加 cuisine chip（蓝色）+ pricePerPerson badge（绿色），只在字段非空 / 非「不想透露」时显示。

#### 最热排序公式改良

[server/db.ts](server/db.ts) hotScore 从 `likes + comments` 改为：

```
likes + comments × 2 + rating × 3
```

评论权重 ×2（互动成本更高）；评分 ×3（让高质量新帖也能露出，5 星 + 0 互动 = 15 分）。

#### AI 回复书名号可点击

服务端（[server/routers.ts](server/routers.ts)）在 AI 回复后用 regex 提取 `《title》`，从上下文 posts 池反查 post ID，返回 `{ reply, references: [{id, title}] }`。前端（[client/src/pages/AiChat.tsx](client/src/pages/AiChat.tsx)）`renderWithLinks` 函数将书名号替换为可点击 `<button>`，跳转 `/post/:id`。

#### 重写发帖提示文字

[client/src/pages/Publish.tsx](client/src/pages/Publish.tsx) — 标题/内容 placeholder 重写为真实细节引导句，外卖/堂食条件化显示，底部加 `💡 别担心写不完整 — 下一步 AI 会自动提取` 说明；极速发按钮加「标签留空，不进类别榜」说明。

### 二、中英文一键切换（i18n）

**目标**：Demo Day 评委是外籍老师，需要一键将所有静态 UI 文案切换为英文。动态数据（帖子标题/正文、用户名）保持原文不动。

#### 技术选型：手写轻量 Context，不引入 i18n 库

- 项目仅 2 种语言、~120 个字符串，`react-i18next` 过重
- 自写 `I18nProvider + useT()` 共 ~80 行核心代码，局部 TypeScript 安全（`en.ts` 用 `en: Translations` 约束，漏译报错）
- `t('key', { var })` 支持 `{var}` 占位符替换

#### 新增文件

| 文件 | 内容 |
| --- | --- |
| `shared/i18n/zh.ts` | 完整中文字典（~120 keys，分 nav / home / feed / rankings / publish / aiChat / postDetail / profile / toast 命名空间） |
| `shared/i18n/en.ts` | 完整英文字典（`en: Translations` 强约束） |
| `client/src/contexts/I18nContext.tsx` | `I18nProvider` + `useT()` hook，`localStorage` 持久化，默认中文 |
| `client/src/components/LanguageToggle.tsx` | `中 / EN` 切换按钮，当前语言粗体高亮 |
